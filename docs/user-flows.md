## Добавление транзакции

Ручной ввод — основной быстрый способ фиксации расхода или дохода.

```mermaid
flowchart TD
    START([Пользователь открывает приложение]) --> DASH[Дашборд]
    DASH --> BTN[Кнопка +]
    BTN --> FORM[Форма добавления транзакции]

    FORM --> TYPE{Тип}
    TYPE -->|Расход| EXP[Заполнить сумму, описание, дату]
    TYPE -->|Доход| INC[Заполнить сумму, описание, дату]

    EXP --> ACC_SEL[Выбрать счёт]
    INC --> ACC_SEL

    ACC_SEL --> SAVE[Сохранить]
    SAVE --> VALIDATE{Валидация}
    VALIDATE -->|Ошибка| ERR[Показать ошибку]
    ERR --> FORM
    VALIDATE -->|OK| PERSIST[Сохранить в БД]
    PERSIST --> RECALC[Пересчитать DailyBudget]
    RECALC --> ZONE[Определить зону дня]
    ZONE --> DASH_UPD[Обновить дашборд]
    DASH_UPD --> END([Готово])
```

## Импорт транзакций из файла или API

```mermaid
flowchart TD
    START([Меню → Импорт]) --> SRC{Выбор источника}

    SRC -->|Файл| FILE_PICK[Выбрать файл CSV/XLSX]
    FILE_PICK --> FILE_PARSE[Парсинг файла]
    FILE_PARSE --> PREVIEW[Предпросмотр транзакций]

    SRC -->|API| API_CFG[Ввести параметры API\nтокен, период]
    API_CFG --> API_FETCH[Запрос к внешнему API]
    API_FETCH --> PREVIEW

    PREVIEW --> REVIEW{Пользователь\nпроверяет данные}
    REVIEW -->|Отмена| CANCEL([Отменено])
    REVIEW -->|Подтвердить| MAP_ACC[Сопоставить счёт]
    MAP_ACC --> IMPORT[Импортировать]
    IMPORT --> DEDUP[Проверка дублей]
    DEDUP --> SAVE[Сохранить новые транзакции]
    SAVE --> RECALC[Пересчитать DailyBudget за период]
    RECALC --> REPORT[Показать отчёт:\nимпортировано / пропущено / ошибки]
    REPORT --> END([Готово])
```

## Создание расчётного периода

```mermaid
flowchart TD
    START([Меню → Периоды]) --> LIST[Список периодов]
    LIST --> NEW[Создать новый период]

    NEW --> FORM[Форма периода]
    FORM --> F1[Название]
    FORM --> F2[Мультивыбор счетов\nодин или несколько]
    FORM --> F3[Дата начала / конца]
    FORM --> F4[Общий бюджет]
    FORM --> F5[Алгоритм лимита]

    F5 -->|ArithmeticMean| ALG1[Среднее + перенос остатков]
    F5 -->|Будущее...| ALG_N[Другой алгоритм]

    ALG1 --> ZONE_CFG[Настроить зоны трат]
    ALG_N --> ZONE_CFG

    ZONE_CFG --> ZONE_LIST[Список зон\nпо умолчанию 3 зоны]
    ZONE_LIST --> ZONE_EDIT[Для каждой зоны:\nНазвание · Цвет · Верхний порог %]
    ZONE_EDIT --> ZONE_ADD[+ Добавить зону]
    ZONE_EDIT --> ZONE_DEL[− Удалить зону]
    ZONE_ADD --> ZONE_EDIT
    ZONE_DEL --> ZONE_EDIT
    ZONE_EDIT --> ZONE_ORDER[Последняя зона — без верхней границы\nперехватывает всё что выше]

    ZONE_ORDER --> SAVE[Сохранить период]
    SAVE --> INIT_DAILY[Инициализировать DailyBudget\nдля каждого дня периода]
    INIT_DAILY --> LIST_UPD[Обновить список периодов]
    LIST_UPD --> END([Готово])
```

## Просмотр дашборда

```mermaid
flowchart TD
    START([Открыть приложение]) --> SEL_ACC[Выбрать счёт]
    SEL_ACC --> SEL_PER[Активный период определяется автоматически]

    SEL_PER --> LOAD[Загрузка данных дня]
    LOAD --> CALC[Расчёт лимита дня]
    CALC --> MED[Расчёт медианы за период]

    MED --> DASH[Дашборд]

    DASH --> BLOCK1[Лимит дня\nОстаток / Перерасход]
    DASH --> BLOCK2[Фактические траты\nЦветовая зона]
    DASH --> BLOCK3[Медиана трат]
    DASH --> BLOCK4[Отклонение от медианы\n+/– в рублях и %]
    DASH --> BLOCK5[График по дням периода]

    BLOCK5 --> NAV{Навигация}
    NAV -->|Предыдущий день| LOAD
    NAV -->|Следующий день| LOAD
    NAV -->|Выбрать период| SEL_PER
```

## Настройка зон трат

Зоны можно изменить в рамках уже созданного периода. Число зон не ограничено.

```mermaid
flowchart TD
    START([Меню → Период → Настройки зон]) --> ZONE_LIST[Список зон периода\nупорядочен по порогу]

    ZONE_LIST --> ACT{Действие}

    ACT -->|Редактировать зону| EDIT[Изменить название / цвет / порог]
    ACT -->|Добавить зону| ADD[Новая зона: название цвет порог]
    ACT -->|Удалить зону| DEL{Не единственная?}

    DEL -->|Нет| ERR_DEL[Ошибка: минимум 1 зона]
    DEL -->|Да| REMOVE[Удалить зону]

    EDIT --> VAL
    ADD --> VAL
    REMOVE --> VAL

    VAL{Проверка}
    VAL -->|Пороги не возрастают| ERR_VAL[Ошибка: порядок нарушен]
    VAL -->|Нет зоны без порога| ERR_LAST[Ошибка: нужна финальная зона\nбез верхней границы]
    VAL -->|OK| SAVE[Сохранить]

    ERR_VAL --> ZONE_LIST
    ERR_LAST --> ZONE_LIST

    SAVE --> RECALC[Пересчитать ActiveZoneId\nдля всех DailyBudget периода]
    RECALC --> ZONE_LIST
```

## Управление счетами

```mermaid
flowchart TD
    START([Меню → Счета]) --> LIST[Список счетов]

    LIST --> ADD[Добавить счёт]
    ADD --> FORM[Название, тип, валюта]
    FORM --> TYPE{Тип счёта}
    TYPE -->|Checking| CHK[Расчётный\nдоступен для бюджетных периодов]
    TYPE -->|Savings| SAV[Сберегательный\nбудущая функциональность]
    TYPE -->|Broker| BRK[Брокерский\nбудущая функциональность]

    CHK --> SAVE[Сохранить]
    SAV --> SAVE
    BRK --> SAVE
    SAVE --> LIST

    LIST --> SWITCH[Переключиться на счёт]
    SWITCH --> DASH[Дашборд выбранного счёта]
```

## Навигация по приложению

Общая структура навигации MAUI-приложения.

```mermaid
graph TD
    ROOT[Главный экран] --> DASH[Дашборд]
    ROOT --> NAV[Боковое меню / Tab Bar]

    NAV --> TRANS_LIST[Транзакции]
    NAV --> PERIODS[Периоды]
    NAV --> ACCOUNTS[Счета]
    NAV --> IMPORT[Импорт]
    NAV --> SETTINGS[Настройки]

    DASH --> ADD_TRX[+ Транзакция]
    DASH --> DAY_DETAIL[Детали дня]

    TRANS_LIST --> TRX_DETAIL[Детали транзакции]
    TRANS_LIST --> ADD_TRX

    PERIODS --> PERIOD_DETAIL[Детали периода]
    PERIOD_DETAIL --> ZONE_SETTINGS[Настройки зон]
    PERIOD_DETAIL --> DAY_LIST[Список дней]

    ACCOUNTS --> ACC_DETAIL[Детали счёта]
    ACC_DETAIL --> PERIOD_DETAIL

    IMPORT --> FILE_FLOW[Импорт из файла]
    IMPORT --> API_FLOW[Импорт из API]
```
