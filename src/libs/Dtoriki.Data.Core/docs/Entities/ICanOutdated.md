## Назначение

Определяет контракт для типов, которые могут помечаться как устаревшие. Независим от `IEntity` — может применяться к любому типу, не только к сущностям БД.

## Интерфейс

```csharp
public interface ICanOutdated
```

## Свойства

#### IsOutdated { get; set; }

Признак устаревания. `true` — данные устарели и не должны использоваться как актуальные; `false` — данные актуальны.

## Инварианты и правила

| Область | Условие | Гарантия |
|---------|---------|---------|
| IsOutdated | Семантика устаревания | Определяется потребителем; библиотека не навязывает переходы |

## Сценарии использования

Сущность с поддержкой устаревания:

```csharp
public sealed class ExchangeRate : SoftDeletableEntityBase, ICanOutdated
{
    public bool IsOutdated { get; set; }
    public decimal Rate { get; set; }
}
```

Фильтрация актуальных записей:

```csharp
ExchangeRate[] rates = await context.Set<ExchangeRate>()
    .Where(r => !r.IsOutdated)
    .ToArrayAsync(cancellationToken);
```

## Ограничения и допущения

| Область | Ограничение |
|---------|-------------|
| Автоматизация | Флаг не устанавливается автоматически; логика перехода — ответственность прикладного кода |
